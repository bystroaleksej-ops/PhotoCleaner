# PhotoCleaner для Android 15

Умный клинер галереи для Android 15 (API 35), написанный на **Kotlin** и **Jetpack Compose (Material 3)**.

## Возможности приложения
1. **Поиск похожих фото и серий (Burst Shots)**:
   - Вычисляет 64-битный перцептивный хэш (`dHash`) для каждого фото.
   - Группирует дубликаты по расстоянию Хэмминга ($\le 5$) и временным меткам EXIF.
   - **Автоматически находит лучшее фото** в серии (по чёткости, разрешению и размеру) и помечает его значком ⭐ "Лучшее", предлагая удалить только дубликаты.
2. **Детектор размытых и нечётких фото**:
   - Анализирует дисперсию Лапласиана (Variance of Laplacian).
   - Выставляет числовой балл чёткости и отсеивает смазанные кадры.
3. **Фильтр скриншотов**:
   - Находит снимки экрана для быстрой очистки памяти.
4. **Безопасное удаление по стандартам Android 15**:
   - Использует системный механизм `MediaStore.createTrashRequest`.
   - Фото перемещаются в системную «Корзину» на 30 дней с подтверждением в диалоговом окне системы (случайно удалить что-то насовсем невозможно).

## Как собрать APK через GitHub Actions (за 2 минуты):

1. Зайдите на [github.com/new](https://github.com/new) и создайте новый репозиторий (например, `PhotoCleaner`).
2. Загрузите файлы проекта (можно перетащить содержимое папки прямо в браузере через кнопку **Add file -> Upload files**).
3. Перейдите во вкладку **Actions**:
   - Сборка **Build Android APK** запустится автоматически!
4. Через ~1.5–2 минуты в разделе **Artifacts** появится готовый файл:
   - **`PhotoCleaner-Debug-APK`** (`app-debug.apk`).
5. Скачайте его на телефон и установите!
